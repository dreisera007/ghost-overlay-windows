# Ghost Overlay v2.1.0

**Click-to-rename.** Click the chat title at the top of the Document Workspace and type a new name.
The real ChatGPT conversation is renamed, so the new title shows in the workspace, in ChatGPT's own
sidebar and history, and on your other devices.

> Independent project, not affiliated with or endorsed by OpenAI, Google or Anthropic.

## Download

**`Install-ChatGPTGhostOverlay.cmd`** (one file, about 215 KB). Double-click it and follow the prompts.
Upgrading from v2.0.4 keeps your settings (opacity, size, mode, startup).

SHA256: `E9E8BAC9535126B0D978D2B15605AB9DFE174B83777B1D4C880947191752E945`

To check it in PowerShell: `Get-FileHash .\Install-ChatGPTGhostOverlay.cmd -Algorithm SHA256`

The installer is **not digitally signed**. It's a plain-text script you can read before running.
Your browser or Windows SmartScreen may warn about an unsigned script from the internet, so verify
the checksum first.

**After upgrading:** open `chrome://extensions` and click **Reload** on "Ghost Overlay Document Mode"
(it should show 2.1.0). New installs load the extension once, by hand: turn on Developer mode, click
**Load unpacked**, and choose `%LOCALAPPDATA%\ChatGPTGhostOverlay\DocumentMode\extension`.

## New

- **Click-to-rename** in the Document Workspace header:
  - Click the title (a pencil appears on hover), type, and press **Enter**. **Escape** cancels; clicking
    elsewhere saves a changed title. Empty titles are refused.
  - The rename goes through ChatGPT's own **Chat actions → Rename** dialog for the conversation that's
    open, identified by its address and never by its title, so chats with the same title are safe.
  - The workspace reports success only after ChatGPT shows the new title. If ChatGPT doesn't confirm,
    the real title comes back, or ChatGPT's own dialog is shown so you can finish there.
  - Works in ordinary chats and in chats inside Projects (the Project itself isn't renamed).
    Temporary and not-yet-saved chats can't be renamed; the workspace tells you why.
  - Header, chat tabs and the Chats menu show the new title at once. A newer title shown by ChatGPT
    (for example renamed on another device) always takes precedence.
- **Opacity diagnostics:** each saved opacity change in `GhostOverlay.log` now also records how many
  Ctrl+Alt+Up/Down presses caused it, whether Ctrl and Alt were physically held, and the program in
  front. No other keys and no text are recorded. This doesn't change how the keys behave: it makes
  occasional unexplained opacity changes traceable (keyboard, AltGr, or keys sent by software). The
  cause of the changes seen so far is not known, and nothing has been "fixed" for it yet.

## Changed

- The header no longer refreshes over the title while you type.
- Clearer wording about what the extension does: no Chrome API permissions, runs only on
  chatgpt.com (manifest description, code comment, installer message, bundled README).

## Known issues

- **Projects menu lists no projects** (since a ChatGPT navigation change; also in v2.0.4). Use
  Projects → All projects… meanwhile. Renaming chats inside projects works.
- ChatGPT's own chat list in an open window can show a chat's older title until that chat is opened or
  the page is refreshed, for example after renaming it on another device.

## Verified for this release

- Click-to-rename in the real application on dedicated test chats (an ordinary chat and a chat in a
  test Project), at desktop size and 430 × 550: Enter, Escape, click-outside, empty title, leaving the
  chat while typing, temporary and unsaved chats, duplicate titles, refresh persistence, and header /
  tab / Chats-menu consistency. Failure handling against the real ChatGPT page: no false success.
- Installer: 13 embedded files identical to the tagged source; fresh install with safe defaults;
  upgrade from the published v2.0.4 installer keeping custom settings; uninstall removes only its own
  copy.
- Installed controller: all five hotkeys, show/hide and focus return, emergency reset (saved opacity
  unchanged), always-on-top, single instance, native app fallback and back, startup path: 24/24 checks.

Details: [docs/TESTING.md](https://github.com/dreisera007/ghost-overlay-windows/blob/v2.1.0/docs/TESTING.md).

## Requirements

Windows 11 (tested on build 26200), AutoHotkey v2, and Google Chrome for the Document Workspace. You
also need your own ChatGPT account. Windows 10 and multiple monitors are untested.
