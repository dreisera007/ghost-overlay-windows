# Ghost Overlay v2.0.4

First public release of **Ghost Overlay — a Windows workspace for ChatGPT**: summon ChatGPT as a
small, semi-transparent, always-on-top overlay with `Ctrl+Alt+G`, laid out as a clean document
workspace.

> Independent project, not affiliated with or endorsed by OpenAI, Google or Anthropic.

## Download

**`Install-ChatGPTGhostOverlay.cmd`** (one file, about 194 KB). Double-click it and follow the prompts.

SHA256: `96CC98DB758F2A3CC0155A79667E74FCEBE6E47DA8A63C39CA7D8C38D907F1DF`

To check it in PowerShell: `Get-FileHash .\Install-ChatGPTGhostOverlay.cmd -Algorithm SHA256`

The installer is **not digitally signed**. It's a plain-text script you can read before running.
Your browser or Windows SmartScreen may warn about an unsigned script from the internet, so verify
the checksum first.

After installing, load the Document Workspace extension once, by hand (a required one-time step,
because Chrome doesn't allow silent installs): open `chrome://extensions`, turn on
Developer mode, click **Load unpacked**, and choose
`%LOCALAPPDATA%\ChatGPTGhostOverlay\DocumentMode\extension`.

## Highlights

- Five global hotkeys: show/hide (`Ctrl+Alt+G`), opacity (`Ctrl+Alt+Up`/`Down`, 5 % steps, 1 %
  floor), always-on-top (`Ctrl+Alt+T`) and emergency reset (`Ctrl+Alt+Shift+R`).
- **Document Workspace:** chatgpt.com in a Chrome app window with menus, toolbar, ruler, page
  widths and a compact layout for small overlays. The extension needs no permissions.
- **Native fallback:** the official ChatGPT Windows app, via `Switch-Mode.cmd ChatGPT`.
- Optional start at Windows sign-in. The window is prepared hidden, so the first show is instant.

## Fixed in this release

- Chats inside ChatGPT Projects no longer collapse to a ~300 px column.
- The controller only attaches to its own chatgpt.com app window, even if other app windows are open.

## Requirements

Windows 11 (tested on build 26200), AutoHotkey v2 (the installer can install it for you), and Google
Chrome for the Document Workspace. You also need your own ChatGPT account.

## Verified for this release

- Installer contents: all 13 embedded files are byte-identical to the tagged source; scripts pass
  AutoHotkey and PowerShell syntax checks.
- Isolated install test into a temporary folder:
  - safe defaults (Document mode, 30 %, 1 % floor, no Chrome profile preset);
  - refuses to start a second copy;
  - mode switching saves correctly;
  - `-Uninstall` removes everything it installed and leaves other copies' Startup shortcuts alone.
- Page widths in ordinary and Project chats at desktop, medium and compact sizes, plus a targeted
  hotkey, startup and fallback regression on the maintainer's machine. Details are in
  [docs/TESTING.md](../TESTING.md).

## Known limitations

Windows 10, multiple monitors and ChatGPT Classic were not tested for this release. The workspace
depends on ChatGPT's page structure and may need an update after ChatGPT changes; meanwhile, use
File → Original ChatGPT layout or `Switch-Mode.cmd ChatGPT`.
